## 四、发布中发现的线上配置缺陷（已修复）

**nginx 双配置遮蔽**：`/etc/nginx/nginx.conf` 内嵌一个 `server_name 49.233.13.110` 的 server 块（历史手工配置）抢走了全部真实流量，而 deploy-server.sh 一直在维护的 `/etc/nginx/conf.d/duban.conf` **从未被 include**——即此前所有经 deploy 下发的 nginx 调整（含本次安全批次的 .map deny）实际从未生效。安全影响：sourcemap 禁下载规则此前不在线（但产物本身 0 个 .map，无实际泄露）。

修复（服务器操作，已备份 nginx.conf.bak-20260829）：摘除内嵌旧块 + 在 http 块补 `include /etc/nginx/conf.d/*.conf;`，reload 后公网全量回归通过（首页/health/业务接口/SSE/静态资源 200，`*.map` 403）。此后 deploy-server.sh 的 nginx 配置才真正"管得着"线上。
